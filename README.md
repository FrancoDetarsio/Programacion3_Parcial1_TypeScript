## Programación 3 - Parcial 1


## Descripción
Proyecto correspondiente al parcial 1 de la matería Programación 3 con el objetivo de integrar herramientas de frontend y desarrollar
un e-commerce con vista del cliente y carrito interactuables

## Herramiéntas
- HTML5
- CSS3
- TypeScript

## Instalación y Uso

### Aclaración
La pagina cuenta con un Login, ya se crearon ususuarios a find de facilitar las pruebas, la vista de cliente
es la que ocupa la funcionalidad actual, con productos y carrito

### 1. Descarga de Proyecto

descargar proyecto en formato .zip y descomprimir

### 2. Instalar Dependencias del Proyecto

Una vez en la carpeta raíz del proyecto, instala las dependencias necesarias con `pnpm`:

```bash
pnpm install
```

### 3. Ejecutar el Proyecto

Para iniciar el servidor de desarrollo de Vite, ejecuta:

```bash
pnpm dev
```

La aplicación estará disponible en la URL que aparezca en la terminal (generalmente `http://localhost:5173`).
